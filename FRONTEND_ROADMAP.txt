1. EXECUTIVE OVERVIEW
--------------------------------------------------------------------------------
The frontend is an aerospace-grade Mission Control and Digital Twin Telemetry
Console for the coarse optical alignment of mobile Free Space Optical
Communication (FSOC) terminals (UAVs, high-altitude platforms, LEO satellites).

It connects via full-duplex WebSocket at 60 FPS (16.6ms cycle) to receive 3D
kinematics, camera projections, YOLOv8 AI detection boxes, 6-DOF Extended Kalman
Filter (EKF) states, dual-axis PID gimbal actuation, and 1550nm optical link
budget metrics.

Target Alignment Benchmark: Pointing Error <= 8.72 mrad (0.50 degrees).

3. THE 8 CORE FRONTEND SUBMODULES
--------------------------------------------------------------------------------

[MODULE 1] NetworkClient (WebSocket & REST API)
- WebSocket Endpoint: ws://localhost:8000/ws/telemetry (60 Hz telemetry streaming)
- Auto-reconnect with exponential backoff.
- Real-time round-trip latency and FPS calculator.
- REST API Calls:
  * POST /api/config          : Update trajectory, weather, laser power, PID gains
  * POST /api/scenario/occlude: Trigger synthetic cloud occlusion
  * POST /api/scenario/wind   : Inject 4.5 m/s wind disturbance
  * POST /api/scenario/reset  : Reset EKF and simulation clock
  * GET  /api/benchmark/report: Fetch automated performance summary JSON
  * GET  /api/benchmark/csv   : Download 100-frame test telemetry CSV

[MODULE 2] DigitalTwin3D (Three.js 3D Spatial World - Section I)
- Three.js WebGL scene with Perspective Camera (FOV 45 deg) & OrbitControls.
- Environment: Sriharikota Launch Range (SDSC SHAR) satellite ground texture,
  concrete launch pad, runway 09/27 markings, and coordinate grid.
- Ground Terminal Model: Heavy pedestal, dual-axis yoke, optical barrel.
- Target UAV Model: Quad-rotor airframe with animated rotating propeller blades.
- 1550nm Laser Beam: Dynamic cylinder connecting ground station aperture to UAV.
  Color reactive: Emerald Green (Error <= 8.72 mrad) / Crimson Red (> 8.72 mrad).
- Volumetric Cloud Mesh: Appears across line-of-sight during occlusion tests.
- Camera Modes:
  * Free Cam    : 360-degree orbital user inspection.
  * Follow Cam  : Dynamic chase camera tracking UAV coordinates.
  * Terminal Cam: Ground station eye-level looking up at the target.

[MODULE 3] VirtualCameraView (Optical Telescope Viewport - Section II)
- Dedicated 1st-person Three.js viewport looking from the ground station barrel.
- Synchronized with gimbal pan/tilt orientation:
  * Pitch = Gimbal Elevation
  * Yaw   = -Gimbal Azimuth
- Matches optical sensor Field of View (45.0 deg default).

[MODULE 4] EOIRTrackingHUD (2D Optical Tracking Canvas Overlay)
- Layered directly over the Virtual Camera viewport.
- Center Reticle: Ground station boresight origin crosshair (u0, v0).
- 8.72 mrad (0.50 deg) Boundary Box: Visual tolerance gate for coarse lock.
- YOLOv8 AI Detection Box: Bounding box around target beacon with confidence %.
- 6-DOF EKF Tracking Layer:
  * Estimated centroid marker (u_hat, v_hat).
  * 3-Sigma Uncertainty Covariance Ellipse (expands during cloud occlusions).
  * 5-Step Future Trajectory Horizon Prediction Trail.
- Live Status HUD: Azimuth/Elevation angular offsets and slant range (m).

[MODULE 5] TacticalMinimap (2D Satellite Radar Inset)
- 2D Canvas radar showing top-down coordinates:
  * Ground station at origin (0, 0).
  * Target location (x, y) with heading vector.
  * Range distance rings (100m, 250m, 500m).
  * GPS Latitude/Longitude readouts (13 deg 43' N, 80 deg 13' E).

[MODULE 6] TelemetryConsole (DOM Metrics & 5-Step Pipeline Strip)
- Hero Readout: Live Pointing Error in mrad and degrees (color-coded).
- 5-Step Pipeline Flow:
  1. Target Flight -> 2. AI Detection -> 3. EKF Prediction ->
  4. Gimbal Slew -> 5. Laser Carrier Lock.
- Actuation: Azimuth/Elevation angles and motor slew rates (bounded to <= 45 deg/s).
- Optical Link: RSSI (dBm & micro-Watts), SNR (dB), Bit Error Rate (BER),
  10 Gbps Lock Status.
- Channel: Trajectory mode, target speed (m/s), weather loss (dB/km).

[MODULE 7] ErrorChart (Real-Time Pointing Error Graph - Section V)
- Real-time scrolling line graph using Chart.js.
- Buffers the last 100 telemetry frames (16.6ms per sample).
- Solid Redline at 8.72 mrad limit.
- Live Statistical Badges: Current Error, RMS Error, Peak Error.

[MODULE 8] EngineeringEventFeed (Timeline Logger - Section VI)
- Auto-scrolling chronological event log.
- Timestamped messages for key mission milestones:
  * Target acquisition / beacon detection.
  * Gimbal slew acceleration / rate saturation.
  * Cloud occlusion triggered (EKF coasting active).
  * Lock re-acquired post-occlusion.
